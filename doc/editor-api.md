# Mankai Editor API Specification

This specification outlines the endpoints required for the editor functionality in [mankai](https://github.com/nohackjustnoobb/mankai).

### Manga Management

#### `POST` `/edit/manga`

Inserts or updates a manga entry.

**Request Body:**

```ts
enum Genre {
  All = "all",
  Action = "action",
  Romance = "romance",
  Yuri = "yuri",
  BoysLove = "boysLove",
  SchoolLife = "schoolLife",
  Adventure = "adventure",
  Harem = "harem",
  SpeculativeFiction = "speculativeFiction",
  War = "war",
  Suspense = "suspense",
  FanFiction = "fanFiction",
  Comedy = "comedy",
  Magic = "magic",
  Horror = "horror",
  Historical = "historical",
  Sports = "sports",
  Mature = "mature",
  Mecha = "mecha",
  Otokonoko = "otokonoko",
}

enum Status {
  Any = 0,
  OnGoing = 1,
  Ended = 2,
}

interface MangaRequest {
  id: string; // if new, a uuid generated by client will be used (can be ignored if server generates its own id)
  title?: string;
  status?: Status;
  description?: string;
  authors: string[];
  genres: Genre[];
  remarks?: string;
}
```

**Response Body (200 OK):**

```ts
interface MangaResponse {
  id: string;
}
```

#### `DELETE` `/edit/manga/:id`

Deletes a manga by its ID.

**Request Parameters:** None

#### `POST` `/edit/manga/:id/cover`

Inserts or updates the cover image for a manga.

**Request Body:**

Raw image data (e.g. `image/png`, `image/jpeg`).

### Chapter Group Management

#### `POST` `/edit/chapter-group`

Inserts or updates a chapter group.

**Request Body:**

```ts
interface ChapterGroupRequest {
  id?: string; // Null if new
  mangaId: string;
  title: string;
}
```

#### `DELETE` `/edit/chapter-group/:id`

Deletes a chapter group by its ID.

**Request Parameters:** None

#### `GET` `/edit/chapter-group/id`

Gets the ID of a chapter group by manga ID and title.

**Request Parameters:**

| Parameter | Type     | Required | Description                     |
| :-------- | :------- | :------- | :------------------------------ |
| `mangaId` | `string` | Yes      | The ID of the manga.            |
| `title`   | `string` | Yes      | The title of the chapter group. |

**Response Body (200 OK):**

```ts
interface ChapterGroupIdResponse {
  id: string | null;
}
```

#### `GET` `/edit/chapter-group/:id/chapters`

Gets the chapters in a chapter group.

**Response Body (200 OK):**

```ts
interface Chapter {
  id: string;
  title?: string;
  locked?: boolean;
}

type ChaptersResponse = Chapter[];
```

### Chapter Management

#### `POST` `/edit/chapter`

Inserts or updates a chapter.

**Request Body:**

```ts
interface ChapterUpsertRequest {
  id?: string; // Null if new
  title: string;
  chapterGroupId: string;
}
```

#### `DELETE` `/edit/chapter/:id`

Deletes a chapter by its ID.

#### `POST` `/edit/chapter/order`

Arranges the order of chapters by their IDs.

**Request Body:**

```ts
type ChapterOrderRequest = string[]; // Ordered list of chapter IDs
```

#### `POST` `/edit/chapter/:id/images`

Adds images to a chapter.

**Request Body:**

```ts
interface ChapterImagesRequest {
  images: string[]; // Array of image data encoded in base64
}
```

#### `POST` `/edit/images/delete`

Deletes images by their URLs.

**Request Body:**

```ts
type DeleteImagesRequest = string[]; // List of image URLs to delete
```

#### `POST` `/edit/images/order`

Arranges the order of images by their URLs.

**Request Body:**

```ts
type ImageOrderRequest = string[]; // Ordered list of image URLs
```
